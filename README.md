# PersonalVoiceAssistant
A Python-based personal voice assistant using speech recognition and text-to-speech.
## Features

- Captures voice through the microphone
- Converts speech into text
- Provides an assistant response
- Uses text-to-speech

## Technologies Used

- Python
- SpeechRecognition
- PyAudioWPatch
- pyttsx3

## How It Works

The assistant listens to the user's voice through the microphone, recognizes the spoken words, and provides a response using text-to-speech.
